# 내캘린더 — 업무 일정체크 캘린더

회계·세무·급여 신고 기한을 놓치지 않기 위한 1인용 업무 캘린더입니다.
세무신고·인사/급여 기본 일정이 미리 들어 있고, 내 업무를 추가해 예정/진행중/완료로 관리합니다.

순수 HTML / CSS / JavaScript로 만들었고, 외부 의존성·빌드 과정이 없습니다. PWA라서 폰 홈 화면에 설치하면 오프라인에서도 열립니다.

## 폰에서 쓰는 법

- **PC에서만 쓸 때**: `index.html`을 더블클릭해서 엽니다.
- **폰에 설치할 때**: 이 폴더를 [GitHub Pages]나 [Netlify Drop](https://app.netlify.com/drop)(폴더를 끌어다 놓기만 하면 됨)에 올린 뒤, 폰에서 그 주소를 열고 브라우저 메뉴에서 **"홈 화면에 추가"**를 누릅니다. 홈 화면 아이콘으로 앱처럼 실행되고, 오프라인에서도 열립니다.
- **데이터 저장 위치**: 데이터는 각 기기의 브라우저(localStorage)에 따로 저장됩니다. 폰과 PC 사이에 동기화되지 않습니다(v2 후보 기능).

## 쓰는 법 요약

- **달력 탭**: 위쪽 "다가오는 신고·납부" 띠에서 임박/지난 기한을 확인하고, 달력에서 날짜를 눌러 그날 일정을 봅니다. 좌우 스와이프로 월을 이동합니다.
- **목록 탭**: 선택한 달의 일정을 분류·완료 상태로 필터링해 봅니다.
- **고정업무 탭**: 매월·매주 반복하는 내 업무를 등록하고, 기본 일정을 켜고 끕니다.
- 각 일정의 **진행상황 칩**을 누르면 예정 → 진행중 → 완료로 순환합니다.
- 오른쪽 아래 **+ 버튼**으로 업무를 추가하고, 일정 상세에서 **다른 날짜로 복사**하거나 날짜 목록에서 **전체 복사**할 수 있습니다.

## 폴더 구조

```
내캘린더/
├── index.html
├── manifest.json
├── sw.js
├── css/style.css
└── js/
    ├── holidays.js       공휴일 목록 (2026·2027)
    ├── base-schedule.js  기본 신고일정 데이터
    ├── dates.js          날짜 유틸 + 영업일 연장
    ├── store.js          저장/불러오기 (localStorage: workcal.v1)
    ├── schedule.js       일정 펼치기
    └── app.js            화면 렌더링과 이벤트
```

## 참고

- 기한이 토·일·공휴일이면 다음 영업일로 자동 연장해 표시합니다(연말정산 안내 등 일부는 그대로 둠).
- 공휴일은 **2026·2027년**을 수록했습니다. 기한 연장 고시가 있으면 홈택스 공지를 우선 확인하세요.
- 기본 일정은 **12월 결산 법인** 기준입니다.
